# snake-game-java
A classic snake game developed using Java for my Object-Oriented Programming course.

**How to Run**

Requirements: Java Development Kit (JDK).

Clone or download this repository.

Open a terminal in the project root directory.

Compile the Java files:

_ _javac -d out src/com/zetcode/*.java_ _

Run the game:

_ _java -cp out com.zetcode.Snake_ _ 

Keep the src/resources/ directory in its original location because the game loads its images using relative file paths.

**Controls**

↑ Up Arrow = Move up 

↓ Down Arrow = Move down

← Left Arrow = Move left

→ Right Arrow = Move right

**Academic Information**

Course: Object-Oriented Programming (OOP)

Language: Java
